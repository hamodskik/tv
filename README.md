# لوحة زبائن عالم محمد تيفي

لوحة لإدارة اشتراكات IPTV: تضيف الزبون وتشوف كم باقي له، وتطلع لك مهام التذكير كل يوم، وترسل رسائل واتساب جاهزة، وتجدد الاشتراك بضغطة.

- **الواجهة:** صفحة وحدة (`index.html`) مرفوعة على GitHub Pages.
- **البيانات:** في Google Sheet خاص فيك، ما تنحفظ في GitHub أبداً.
- **الربط:** كود Apps Script (`apps-script/Code.gs`) محمي بكلمة سر.

```
الجوال / اللابتوب  ──►  GitHub Pages (index.html)  ──►  Apps Script  ──►  Google Sheet
                                                        (كلمة سر)
```

---

## التجهيز (مرة وحدة، تقريباً 10 دقائق)

### 1) جهّز الشيت
1. افتح [sheets.new](https://sheets.new) وسمّه مثلاً **زبائن محمد تيفي**.
2. من القائمة: **Extensions ← Apps Script** (الإضافات ← برمجة التطبيقات).
3. امسح الكود الموجود، والصق محتوى الملف [`apps-script/Code.gs`](apps-script/Code.gs) كامل.
4. في أول سطر غيّر كلمة السر:
   ```js
   const PASSWORD = 'اكتب-كلمة-سر-قوية';
   ```
5. اضغط 💾 **Save**.

### 2) انشر الكود كـ Web App
1. فوق يمين: **Deploy ← New deployment**.
2. من الترس ⚙️ اختر **Web app**.
3. اضبط:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. اضغط **Deploy** ← **Authorize access** ← اختر حسابك.
   - إذا طلع لك "Google hasn't verified this app": اضغط **Advanced** ثم **Go to ... (unsafe)**. هذا طبيعي لأن الكود حقك أنت.
5. انسخ الرابط **Web app URL**، وهو ينتهي بـ `/exec`.

### 3) ادخل اللوحة
1. افتح رابط اللوحة على GitHub Pages.
2. الصق رابط `/exec` واكتب كلمة السر واضغط **دخول**.
3. الجهاز يتذكر الدخول. كرر الخطوة هذي مرة وحدة على كل جهاز (الجوال واللابتوب).

> 💡 على الجوال: من المتصفح اختر **إضافة إلى الشاشة الرئيسية**، وتصير اللوحة مثل التطبيق.

---

## إذا عدّلت كود Apps Script
**Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**.
الرابط يبقى نفسه، وما تحتاج تدخل من جديد.

## الأمان
- كلمة السر موجودة **بس** داخل Apps Script في حسابك، مو في GitHub.
- لا ترفع أي ملف فيه بيانات زبائن على GitHub، لأن المستودع العام يقدر يشوفه أي أحد.
- لو تسربت كلمة السر: غيّرها في `Code.gs` وسوّ **New version**، وكل الأجهزة بتطلب دخول من جديد.
- من الإعدادات في اللوحة فيه زر **تسجيل خروج من هالجهاز**.

## الشيت نفسه
- ورقة **الزبائن**: كل زبون في صف، وعمود **الأيام المتبقية** يتحسب ويتلون لحاله.
- ورقة **الإعدادات**: الأسعار ورابط الدفع (عدّلها من اللوحة، مو من الشيت).
- عمودي **الدفعات** و**الرسائل المرسلة** فيها بيانات للوحة، لا تعدلها بيدك.
