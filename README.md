# لوحة زبائن عالم محمد تيفي

لوحة لإدارة اشتراكات IPTV: تضيف الزبون وتشوف كم باقي له، وتطلع لك مهام التذكير كل يوم، وترسل رسائل واتساب جاهزة، وتجدد الاشتراك بضغطة.

```
الجوال / اللابتوب ──► GitHub Pages (index.html) ──► Supabase (قاعدة البيانات + تسجيل الدخول)
```

- **الواجهة:** `index.html` على GitHub Pages
- **البيانات:** في Supabase، ومحمية بقواعد صلاحيات داخل قاعدة البيانات نفسها
- **الدخول:** إيميل وكلمة سر لكل شخص، والتسجيل الذاتي مقفول

| الملف | وش هو |
|---|---|
| `index.html` | اللوحة |
| `config.js` | رابط مشروع Supabase والمفتاح العام |
| `supabase/schema.sql` | الجداول والصلاحيات، تلصقه مرة وحدة في Supabase |

---

## التجهيز (مرة وحدة، تقريباً 10 دقائق)

### 1) سوِّ مشروع في Supabase
1. ادخل [supabase.com](https://supabase.com) وسجّل (ببلاش).
2. **New project**:
   - **Name:** `tv`
   - **Database Password:** اضغط Generate واحفظها في مكان آمن (ما راح تحتاجها في اللوحة)
   - **Region:** اختر الأقرب لك، مثل `Frankfurt` أو `Mumbai`
3. استنى دقيقتين لين يجهز.

### 2) سوِّ الجداول
1. من القائمة: **SQL Editor ← New query**.
2. الصق محتوى [`supabase/schema.sql`](supabase/schema.sql) كامل ← **Run**.
3. لازم يطلع **Success. No rows returned**.

### 3) اقفل التسجيل وسوِّ حسابك
1. **Authentication ← Sign In / Providers**، وطفّي **Allow new users to sign up** ← Save.
   > هذا يمنع أي أحد يسوي لنفسه حساب.
2. **Authentication ← Users ← Add user ← Create new user**:
   - إيميلك وكلمة سر قوية (12 خانة أو أكثر)
   - فعّل **Auto Confirm User**

### 4) أضف نفسك كمالك
في **SQL Editor** شغّل هذا، بعد ما تغيّر الإيميل لإيميلك:
```sql
insert into public.staff (user_id, role)
select id, 'owner' from auth.users where email = 'اكتب-إيميلك-هنا'
on conflict (user_id) do update set role = 'owner';
```

### 5) اربط اللوحة
1. **Project Settings ← API** (أو **Data API**).
2. انسخ:
   - **Project URL** مثل `https://abcd1234.supabase.co`
   - **anon public** key (مفتاح طويل يبدأ بـ `eyJ`)
3. حطهم في `config.js`، أو أرسلهم لـ Claude يحطهم لك.

> ✅ مفتاح **anon** آمن ومصمم يكون عام، والحماية من قواعد قاعدة البيانات.
> ⛔ **لا تشارك أبداً** مفتاح `service_role` ولا كلمة سر قاعدة البيانات.

### 6) ادخل
افتح **https://hamodskik.github.io/tv/** وادخل بإيميلك وكلمة السر.

> 💡 على الجوال: من المتصفح اختر **إضافة إلى الشاشة الرئيسية**، وتصير اللوحة مثل التطبيق.

## 🤖 الأتمتة (ملخص الصبح والتذكيرات التلقائية)

### التركيب (مرة وحدة)
1. **SQL Editor ← New query**، والصق [`supabase/automation.sql`](supabase/automation.sql) ← **Run**.
   - لو طلع خطأ عن `pg_cron` أو `pg_net`: فعّلهم من **Database ← Extensions** وشغّله مرة ثانية.
2. في اللوحة اضغط **🤖 الأتمتة**.

### ☀️ ملخص الصبح
يوصلك كل يوم في الساعة اللي تختارها، وفيه: النشطين، ومين ينتهي اليوم أو بكرة، ومين ينتهي قريب، ومين انتهى وما جدد، ودخل الشهر.
- **تيليجرام (ببلاش):** سوِّ بوت من `@BotFather` وخذ الـ Token، واضغط Start في البوت حقك، وخذ الـ Chat ID من `@userinfobot`.
- **واتساب:** يحتاج ربط Green-API (تحت).

### 🟢 ربط واتساب (Green-API)
1. سجّل في [green-api.com](https://green-api.com) وسوِّ Instance.
2. من واتساب الجوال: **الأجهزة المرتبطة** ← امسح الـ QR.
3. انسخ `apiUrl` و `idInstance` و `apiTokenInstance` وحطها في اللوحة.

### 🤖 التذكيرات التلقائية
- كل يوم في الساعة اللي تختارها، تتجهز تذكيرات الزبائن المستحقة (أسبوع، 3 أيام، يوم، انتهى، فحص الجودة، نهاية التجربة).
- **تنرسل وحدة كل 1–2 دقيقة** بس، وفي الوقت المسموح اللي تحدده، عشان تحمي رقمك.
- تشوفها في **مهام اليوم ← الرسائل التلقائية**، وتقدر تلغي أي وحدة قبل لا تنرسل.
- لما توصل الرسالة، الزبون يتعلّم ✓ تلقائياً.

## 🧪 التجارب المجانية

شغّل `supabase/trials.sql` مرة وحدة (بعد `panel.sql`). بعدها في تبويب **البانل** تلقى **🧪 التجارب المجانية**: تختار التجربة وتكتب الاسم والجوال (اختياري)، وتطلع لك رسالة جاهزة فيها اليوزر والباس والرابط.

- التجربة ما تنضاف كزبون ولا تنحسب في الأرباح.
- اللوحة والقاعدة يقبلون باقات التجربة المجانية بس (0 كريدت)، فما ينخصم رصيد.
- بعد ما تخلص التجربة يطلع زر **📣 تابعه**، وزر **✅ سجّله زبون** لو اشترك.

## 📣 الحملات التلقائية

1. شغّل `supabase/campaigns.sql` مرة وحدة في SQL Editor، بعد `automation.sql`.
2. في تبويب **الحملات** ← **5. الإرسال**، اختر **🤖 تلقائي (Green-API)**.
3. حدد كم رسالة كل ساعة (افتراضي 5)، والفرق بين كل رسالة (دقيقتين)، والحد اليومي (40).
4. جرّب على رقمك أول، وبعدها اضغط **ابدأ**.

- الرسايل تطلع من السيرفر حتى لو اللوحة مقفلة، وفي ساعات الإرسال المحددة في الأتمتة بس.
- الصيغة تتغير كل 5 أشخاص (تقدر تغير الرقم)، والكلمات اللي بين أقواس مثل `{هلا|أهلين}` تنختار وحدة مختلفة لكل شخص.
- الرقم ما توصله حملة ثانية خلال 3 أيام، والزبون النشط يتم تجاوزه.
- لو فشلت 3 رسايل ورا بعض، الحملة توقف لحالها ويوصلك تنبيه.
- **قوائم الأرقام:** لكل سيرفر قائمة محفوظة في Supabase (الرقم يقدر يكون في أكثر من سيرفر)، وفيها "🚫 لا ترسل له".
- **السيرفر في الحملة:** تختار السيرفر، و`{السيرفر}` و`{السعر}` (سعر السنة) يتعبون منه تلقائياً.
- **النماذج المحفوظة:** تحفظ ضبط الحملة (السيرفر والهدف والأسلوب والنص والعرض) باسم وترجع له بضغطة.
- **النتيجة:** كل حملة تعرض كم واحد اشترك أو جدد خلال 14 يوم من رسالته.

## 🔗 ربط البانل (Reseller API)

يسحب خطوطك من البانل ويربطها بزبائنك **باليوزر**، ويحدّث تلقائياً: تاريخ الانتهاء، والباسورد، والجوال (لو مكتوب في اسم الخط). ويعرض رصيد الكريدت.

1. **SQL Editor**: شغّل [`supabase/panel.sql`](supabase/panel.sql).
   - لو طلع خطأ عن `http`: فعّله من **Database ← Extensions** وشغّله مرة ثانية.
2. في البانل: **API Reseller ← Create key** واختر **General**. **لا تفعّل HMAC ولا قيد IP**.
3. في اللوحة: تبويب **البانل ← ربط البانل**، وحط رابط البانل (مع البورت) والمفتاح، واضغط **حفظ**.
4. أول مزامنة تبدأ خلال دقيقة، وبعدها كل يوم في الساعة اللي تحددها.
5. الخطوط اللي ما لها زبون تطلع في تبويب البانل: **استورد** كزبون جديد، أو **اربط** بزبون موجود، أو **استورد كل الفعّالة** مرة وحدة.

> المزامنة **تقرأ بس**: ما تسوي خطوط ولا تصرف كريدت. والمفتاح محفوظ داخل Supabase، وما يطلع في اللوحة ولا في GitHub.

## إضافة موظف
1. **Authentication ← Users ← Add user** (إيميله وكلمة سر).
2. في SQL Editor:
```sql
insert into public.staff (user_id, role)
select id, 'staff' from auth.users where email = 'ايميل-الموظف';
```
الموظف يقدر يضيف زبائن ويعدلهم ويجددهم، بس **ما يقدر يحذف** ولا يغير الإعدادات.

لإيقاف موظف: احذفه من **Authentication ← Users**.

## الأمان
- المستودع ما فيه أي بيانات زبائن ولا كلمات سر.
- لو أحد فتح رابط اللوحة يشوف شاشة دخول بس.
- الصلاحيات مطبقة **داخل قاعدة البيانات**. حتى لو أحد عدّل كود اللوحة عنده، ما يقدر يوصل لشي.
- لو ضاع جوالك: **Authentication ← Users** ← حسابك ← غيّر كلمة السر.

## النسخ الاحتياطي
- **Table Editor ← customers ← Export to CSV** تحفظ نسخة في أي وقت.
- **Table Editor ← customers_status** يعرض لك الزبائن مرتبين حسب الأيام المتبقية.
